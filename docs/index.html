BleeOS

A tiny 32-bit hobby OS: ASM boot, C kernel, POSIX-ish shell, double-buffered GUI desktop, installer, network, and offline packages.

Try itBrowse packages

Features

Boot anywhere

Floppy, hard disk, and El Torito CD on BIOS; FAT16 ESP with a freestanding BOOTX64.EFI loader on UEFI.

Shell

Line editing, history, quoting, $VAR, && lists, redirection, ramfs with /etc, plus help and man pages.

GUI desktop

Login screen, overlapping windows, taskbar clock. Apps: Terminal, Doom clone, Calculator, ASCII Animator, File Explorer, Display settings.

Users

Salted password DB shared by text and graphical logins; persists across reboots on HDD installs. Default login: root / root.

Installer

Debian-like TUI wizard writes a universal BIOS+UEFI image with verification. Needs a disk ≥ 33 MB.

Network

E1000 driver with static SLIRP config, ARP cache, and ICMP echo — ping your gateway.

USB input

USB HID keyboard/mouse over xHCI and UHCI with PS/2 fallback, in both shell and GUI.

Packages

Offline .blee archives installed with pkg; published and CI-verified through this site.

Try it

git clone https://github.com/bleezhi/bleeos.git
cd bleeos
make run         # floppy + GUI (needs QEMU + KVM)
make run-cd      # bootable ISO
make run-uefi    # UEFI via OVMF
make run-install # floppy + blank HDD, then `install`
make iso         # build bleeos.iso

Packages

Offline .blee archives (scripts + data) installed with the in-OS pkg tool. Browse the package index, download a .blee, put it on an attached disk, and run:

pkg install-hd 2048
pkg list
run /pkg/hello/hello.sh

Packagers: see tools/mkblee.py and packages/ in the repo.
