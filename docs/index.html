A tiny 32-bit hobby OS

BleeOS boots from floppy, hard disk, or CD into a shell, a double-buffered GUI with a login screen, and a Debian-like text installer. Login accounts, an ATA driver, and a stub USB detector included. No network stack yet — packages travel on disk.

Try it

git clone https://github.com/bleezhi/bleeos.git
cd bleeos
make run        # floppy + GUI (needs QEMU + KVM)
make run-cd     # bootable ISO
make run-install # floppy + blank HDD, then `install`
make iso        # build bleeos.iso

Packages

Offline .blee archives (scripts + data) installed with the in-OS pkg tool. Browse the package index, download a .blee, put it on an attached disk, and run:

pkg install-hd 2048
pkg list
run /pkg/hello/hello.sh

Default login: root / root. Packagers: see tools/mkblee.py and packages/ in the repo.
