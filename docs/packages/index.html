Publish yours

User packages are welcome. Fork the repo, add packages/<name>/ (PKGINFO + files), run make pkgs, add your row to docs/packages.json (by = your handle), and open a pull request. CI rebuilds every package from source, rejects rule violations and stale files, and rejects an index that disagrees with the built archives. Merge is moderation. Full rules: packages/.

Make one

mkdir -p mypkg
printf 'name=mypkg\nversion=1.0\n' > mypkg/PKGINFO
echo 'echo hi' > mypkg/hi.sh
python3 tools/mkblee.py mypkg mypkg.blee

Limits: archive ≤ 8192 bytes, paths ≤ 64 chars, files ≤ 768 bytes, 32 files max. Format: magic BLEEPKG1, name, version, entries, FNV-1a checksum.
