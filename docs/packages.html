Offline .blee files. Write one to raw disk sectors (e.g. dd if=hello.blee of=hdd.img bs=512 seek=2048 conv=notrunc), attach the disk, then pkg install-hd 2048 in BleeOS.

mkdir -p mypkg

python3 tools/mkblee.py mypkg mypkg.blee

Limits: archive ≤ 8192 bytes, paths ≤ 64 chars, files ≤ 768 bytes, 32 files max. Format: magic BLEEPKG1, name, version, entries, FNV-1a checksum.
